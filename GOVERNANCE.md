# Governance

Shell Studio is maintained by consensus among active maintainers. Maintainers
review contributions for user safety, compatibility with documented Nilesoft
Shell behavior, accessibility, and maintainability.

Changes to configuration storage, privilege handling, release signing, or the
minimum Windows version require public design discussion before merge. Routine
fixes may be merged after one approving review and passing required checks.

Releases are created from protected `main` commits using signed semantic tags.
No published tag is moved or reused.
