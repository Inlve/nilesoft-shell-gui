# Support

- Use **Discussions** for setup questions and NSS configuration help.
- Use the bug report template for reproducible Shell Studio defects.
- Use the compatibility template when a valid NSS construct is parsed or saved
  incorrectly.
- Use private security advisories for vulnerabilities.

Attach the Shell Studio version, Nilesoft Shell version, Windows version, and a
minimal redacted configuration. Do not post secrets, private paths, or personal
data from `shell.log`.
